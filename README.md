## What I’m building: HazelJS Agent OS

[HazelJS](https://github.com/hazel-js/hazeljs) is an open-source Agent OS for TypeScript. I started it to solve a problem that shows up as soon as an agent moves beyond a demo: it needs to work reliably with people, tools, and state that outlive a single request.

Imagine an ecommerce agent that looks up an order and prepares a refund. A person should approve the refund before the agent sends it. If the server restarts while that approval is pending, the workflow should be able to resume without issuing the refund twice.

That’s the kind of engineering I focus on: **durable workflows, human approvals, tool permissions, and a record of what happened.**
